# Maatu

Spoken-only language practice: live real Indian scenarios (auto stand, delivery gate, customer care, airport, chai stall, music classroom) with AI characters voiced by Sarvam, in Kannada, Hindi, and Tamil. No reading, no script, just talk.

- Plan and briefs: `docs/plan/`
- Standing rules: `CLAUDE.md`
- Status: `TASKS.md`
- Frontend: Next.js PWA (this repo root), Vercel
- Voice agent: `agent/` (Python, livekit-agents, runs on the Mac mini)

A Nathaniel School of Music project by Jason Zac.

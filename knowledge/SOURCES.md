The public classes page calls a public class "testing before committing". The main, guitar and singing sites say we offer no free demo sessions. This file follows the no-trial rule and leaves the free assessment out. School records say Jason Zac reviews audition clips himself; the portal says "our team" does. Please confirm.
2. **Founding year.** Main website and brochures: 2007. Piano site and school records: 2008. Learning Portal: "since 2004". nsm-school.md now says only "more than 18 years" until Jason confirms the year.
3. **Student numbers.** Main website: 6,000+ students, 30+ countries. Learning Portal: 500+ active students, 10+ countries. This file uses the main website.
4. **Instruments.** The main website lists four (piano, guitar, vocals, bass). The brochures add drums, violin and trumpet. The portal adds Carnatic music, drums, Indian classical vocals and music production. This file lists the four only.
5. **Recordings.** The portal says recordings stay "forever". School records (4 July 2026) say about one year after the course, and downloads can be kept. This file gives no time limit.
6. **Hours and billing.** The private lessons page says monthly billing and unused hours carry forward. School records say six-month plans and no separate make-up classes for groups. This file avoids billing.
7. **Instalments.** The group lessons page offers instalments. School records say case by case only. This file sends it to the advisor.
8. **Group size.** Portal 4 to 8, guitar 2 to 3, vocals 4 to 8, school records 3 to 7 online.
9. **Age.** Websites: 7 to 75+. Main FAQ: six-month course for ages 8 and above, and also "whether you're 6 or 60". School records: 9 and above for some studio classes.
